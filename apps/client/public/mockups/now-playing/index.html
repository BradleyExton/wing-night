Now Playing — display strip & host controls

The strip the TV shows while music is playing, and the block the host taps to control it. Both render the server's musicPlayback state; neither decides anything. Two sources reach the same strip — the SETUP lobby playlist and a team's anthem at MINIGAME_INTRO — so the label is what distinguishes them, not a different shape.

01 · Lobby playlist, playing

Full-bleed row directly above the fixed standings footer (§2.2: the footer stays, the display never scrolls). Title is derived from the filename — 01-hot-in-herre.mp3 — so the lobby directory stays drop-files-in-and-go. The equalizer is the state indicator: it moves only while the music is actually playing.
