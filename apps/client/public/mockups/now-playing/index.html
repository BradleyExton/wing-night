Now Playing — display pill & host controls

The pill the TV shows while music is playing, and the block the host taps to control it. Both render the server's musicPlayback state; neither decides anything. Two sources reach the same pill — the SETUP lobby playlist and a team's anthem at MINIGAME_INTRO — so the label is what distinguishes them, not a different shape.

01 · Lobby playlist, playing

Floats in the top-right corner of the display, opposite the brand cluster and over whatever the stage is doing — music runs underneath the night, so it takes the quietest corner instead of a band of its own. Title is derived from the filename — 01-hot-in-herre.mp3 — so the lobby directory stays drop-files-in-and-go. The equalizer is the state indicator: it moves only while the music is actually playing. No "n of m" position: that is host-deck detail, and the room only needs to know what is playing.

04 · Host control deck group

A deck group in the control deck (§2.0A), not a media-player chrome strip: the tablet is sauce-covered and thumb-driven, so two 56px targets and nothing else. No volume — the TV's own remote is what people actually reach for — and no scrub, which needs a position the server deliberately does not track.
