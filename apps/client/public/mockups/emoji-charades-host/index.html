Emoji Charades Host (Tablet) — Mockups

Three takes on the picker surface for the EMOJI_CHARADES minigame. All show mid-turn playing state — subject visible, a 20-emoji clue already built, Got It / Skip / backspace / clear all reachable. Built for ~16:10 landscape.

The question these answer: how does the picker work under a 90-second clock? The three variants disagree about the primary affordance — hunt, type, or reach — not about colour. Open at roughly 1600×1000 (or full-screen) for a tablet-accurate preview. All three share the Spicy Broadcast tokens.

01

Tab Deck

The spec read literally, fitted to the §2.0A host shell. Eight category tabs over a dense 10-column grid on the left; subject card, Got It / Skip and the utility row in a right-hand control deck. Most consistent with the rest of the host app — and the one that puts tab-hunting on the critical path.

02

Search First

Inverts the hierarchy: a glowing search field is the primary affordance and results stream horizontally as you type. No categories at all. Costs the bottom half of the tablet to an on-screen keyboard, so the clue canvas and subject compress into a full-width banner and the verdicts become a bottom CTA strip. Fast if you already know the emoji you want; expensive if you don't.

03

Thumb Wheel

Optimizes for a tablet held in two hands. No tabs, no search — one flat frequency-ranked set splayed into two quarter-circle arcs anchored in the bottom corners, inner rings nearest the thumbs. Got It / Skip sit directly under each thumb. Bets that ~90 well-chosen emoji beat 300 categorized ones.
