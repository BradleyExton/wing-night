SILHOUETTE — does the genre change the bird itself?

Brad's question, and his own doubt: "like the metal birds being spiky birds, hardcore... but maybe that doesn't apply to the other ones. I don't know." This page answers it with pictures. Four genres, four birds, each built only from its own anatomy — body, comb, tail, wing edge, how much leg shows. No props, no apparel. Same 80×72 box, same foot at (38,71), same head centre, same pivots, same primary legs, so these birds can stand beside the apparel pages honestly.

Read the line-up first — it is the whole test, and it comes before the four anatomies that explain it. Read it in the colour-stripped version too: every team already has its own hue, so a coloured line-up would separate even if the shapes did nothing. Then the clone rows near the bottom, which were meant to be the argument against all of this and turned out to be the argument for it.
